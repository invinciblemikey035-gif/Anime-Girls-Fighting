# Anime-Girl_Fighting

2D Android anime fighting game prototype.

## Included
- 12-character roster
- Makima and Reze slots
- Touch fighting controls
- HP bars and round flow
- Password-protected Owner Mode
- Owner password: `invincible`
- Owner can unlock all characters, add coins, and restore HP
- Android launcher icon
- GitHub Actions workflow for APK build

## Build on GitHub
Upload the contents of this folder to a GitHub repository.
Open **Actions → Build APK → Run workflow**.
The generated debug APK is uploaded as an Actions artifact named `Anime-Girl-Fighting-debug`.

## Important
The character names belong to their respective anime franchises. For a public commercial release, use artwork/assets you have permission to distribute.
